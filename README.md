<h1 align="center">Hey, I'm Mohamed 👋</h1>
<h3 align="center">Full-stack & IoT developer building real-time industrial software</h3>

<p align="center">
I design and ship systems that connect physical hardware to the software people run their operations on — from ESP32 sensor nodes streaming over MQTT to the dashboards and databases that turn that data into decisions.
</p>

---

### 🔧 What I'm building

- **CMMS platforms** — maintenance management software with IoT sensor ingestion, preventive scheduling, and MTTR/MTBF analytics, built for real production environments
- **Embedded firmware** for current-sensing hardware (ESP32) — calibration, offline data persistence, self-healing, and OTA updates for unattended field deployment
- **A facial-recognition photo distribution app**, mostly as a deliberate excuse to get hands-on with vector search and ML inference in a Node.js stack

I like problems where the interesting part isn't the UI — it's making sure a signal from a sensor on a factory floor survives a bad network connection, a power blip, and six months of unattended uptime, and still ends up as a trustworthy number on someone's dashboard.

### 🌱 Currently

- Deepening my software architecture and system design skills
- Working AI/ML integration into the products I build, with an eye toward eventually building my own company around it
- Chasing a few AWS certifications

### 🎓 Background

Computer engineering graduate, freelancing in full-stack + IoT development for industrial clients. Active in IEEE — I've organized hackathons and presented on blockchain/Web3. I got into this through graphic design at 16, which is probably why I still care more than most backend developers about how the thing actually looks.

All project write-ups live at **[mohameddhif.dev](https://mohameddhif.dev)**.
